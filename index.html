UE5 物理灯光 (PBL) 完整参考

基于真实世界照度数据的 Unreal Engine 5 物理灯光工作流参考手册。涵盖不同时段的 Lux / EV100 / 色温参数及其相互关系。

核心概念
UE5中不同类型的灯光使用不同的物理单位。Directional Light 使用 Lux（照度），Point/Spot/Rect Light 可选 Candela 或 Lumen，Emissive 和 SkyLight 使用 cd/m²（亮度）。

单位之间的关系
Lux → Candela：Lux衡量到达表面的光照强度（照度），Candela衡量光源在某方向上的发光强度。在UE中，当Point Light用Candela定义时，其亮度不受锥角影响；用Lumen定义时则会受影响。
Lumen → Candela：对于各向同性点光源，Candela = Lumens / (4π)。对于Spot Light，Candela = Lumens / (2π × (1 - cos(半角)))。
实际意义：太阳约120,000 lux，60W灯泡约800 lumen（≈64 candela），两者差距约60–1000倍。这就是为什么用任意值打光时添加几盏灯就会破坏平衡。
PBL的核心在于让灯光的Lux/Lumen值和相机的曝光（EV100）在数学上一致。

EV100 公式

EV100 = log₂( N² / t × 100 / S )
N = 光圈值，t = 快门时间(秒)，S = ISO
例: f/8, 1/125s, ISO100 → EV100 ≈ 13

Lux → EV100

EV100 = log₂( E × S / C )
E = 照度(lux)，S = ISO(通常100)，C = 入射光常数(250)
例: 100,000 lux → EV100 ≈ 15.3

曝光计算（UE内部）

Exposure = 1 / ( 1.2 × 2^EV100 )
UE内部用此公式将EV100转为亮度缩放系数
例: EV100=15 → Exposure ≈ 0.0000254

单位换算

1 lux = 1 lm/m² ｜ 1 cd = 1 lm/sr
lux(照度) / lumen(光通量) / candela(光强)
UE中 Directional Light 用 lux，Point/Spot 用 cd 或 lm

核心思路：先确定曝光，再设置光源，最后调节氛围。
1

项目设置

确保 Extend Default Luminance Range 已开启（UE5.1+ 默认开启）。

2

Post Process Volume 曝光

使用 Manual 计量模式。锁定 Min/Max EV100 为同一值（正午≈15，室内≈7）。

3

Directional Light（主光源）

正午=100,000–120,000 lux，Golden Hour=20,000–40,000，阴天=5,000–10,000。调角度、色温，开启 Atmosphere Sun Light。

4

Sky Light（环境光）

开启 Real Time Capture，Intensity≈1.0。它决定阴影明暗和Key/Fill比。

5

Sky Atmosphere / HDRI

方案A: Sky Atmosphere（最物理正确）。方案B: HDRI天空球（更大艺术控制）。

6

室内/人工光源

使用真实Lumen/Candela值。开启 Inverse Squared Falloff。优先用色温而非直接调色。

7

对比度和层次

用 HDR 可视化模式检查亮度。微调 SkyLight Intensity 控制对比。加 Height Fog 增加层次。

8

后处理调色

Tone Mapper（推荐ACES）、Bloom、Vignette、Color Grading。室内外混合用 Local Exposure。

⚠️ 常见陷阱
1. 忘记设曝光 → 100,000 lux + 默认EV = 全白
2. Auto Exposure干扰 → 用Manual模式锁定
3. Lux已含天空贡献 → Directional Light值应略低于参考总Lux
4. 夜间过暗 → 月光0.25 lux可适当"作弊"提亮至1–5 lux
5. Indirect Lighting在高Lux下可能无效
🔗 参数相互影响关系
Directional Light (Lux) → 场景直接照明绝对亮度 → 决定 EV100 选择
EV100 → 相机"看到"多少光 → 通过光圈/快门/ISO间接设定
SkyLight → 填充阴影 → 其与Directional Light的比例 = 场景对比度
Exposure Compensation → EV100基础上±微调 → 不改变物理值
Bloom / Fog → 依赖正确HDR亮度值才有物理正确效果

光源决定物理亮度，曝光决定画面亮度，后处理决定画面氛围。光源强度×2 = EV100+1档，画面亮度不变但Bloom和HDR表现改变。
